# Contributing

Keep changes small, tested, documented, and compatible with the supported Python versions.

## Guidelines

- Prefer the standard library when it is sufficient.
- Keep public APIs explicit and predictable.
- Add or update tests for behavior changes.
- Preserve stable CLI output unless the interface change is intentional.
- Document new public functions, commands, and configuration.

## Pull Requests

Keep each pull request focused on one improvement. Include the motivation, validation performed, and any compatibility considerations.
